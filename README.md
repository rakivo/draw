# [draw](https://github.com/rakivo/draw)

# Quick Start
> build with [rush](https://github.com/rakivo/rush)
```console
$ rush
```
> build with bash
```console
$ ./build.sh
```
> # run
```console
$ ./build/paint
```

# Key Bindings
- [`space`]: panning mode
- [`c`]: invoke color selector menu
- [`b`]: resize brush radius with mouse wheel

# Goal
> I started this project because I was unsatisfied with the niche paint-like programs. Sometimes I want to quickly visualize or sketch something, but the program is too slow and clunky. So, I decided to create my own ultra lightweight ultra-mega fast paint program.
